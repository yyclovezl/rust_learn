# 10.泛型类型、特征Traits和生命周期

具体类型或其他属性的抽象替代项。可以表达泛型的行为或它们与其他泛型的关系，而无需知道在编译和运行代码时它们的位置是什么。

泛型允许用一个占位符（可以表示多种类型）替代特定类型，达到适用与多种类型，减少代码的目的。

例如，先用一个普通函数实现减少代码冗余的目的：

```rust
fn main() {
    let number_list = vec![34, 50, 25, 100, 65];

    let mut largest = &number_list[0];

    for number in &number_list {
        if number > largest {
            largest = number;
        }
    }

    println!("The largest number is {largest}");


    let number_list = vec![102, 34, 6000, 89, 54, 2, 43, 8];

    let mut largest = &number_list[0];

    for number in &number_list {
        if number > largest {
            largest = number;
        }
    }

    println!("The largest number is {largest}");
}
```

代码分别对2个list进行找出最大数的操作，但明显重复很多代码。进行一层抽象，添加函数 ：

```rust
fn largest(list: &[i32]) -> &i32 {
    let mut largest = &list[0];

    for item in list {
        if item > largest {
            largest = item;
        }
    }

    largest
}

fn main() {
    let number_list = vec![34, 50, 25, 100, 65];

    let result = largest(&number_list);
    println!("The largest number is {result}");

    let number_list = vec![102, 34, 6000, 89, 54, 2, 43, 8];

    let result = largest(&number_list);
    println!("The largest number is {result}");
}
```

## 10.1泛型

用泛型为 函数签名（参数） 、 结构体、枚举、方法等项目 创建定义，然后将定义 与 许多不同的具体数据类型一起使用。

### 函数内定义泛型

泛型放在函数的签名中。

回到前面的例子中，现在我们提高需求 ：不仅支持值是i32的列表，同时还支持值是char值的列表 ：

```rust
fn largest_i32(list: &[i32]) -> &i32 {
    let mut largest = &list[0];

    for item in list {
        if item > largest {
            largest = item;
        }
    }

    largest
}

fn largest_char(list: &[char]) -> &char {
    let mut largest = &list[0];

    for item in list {
        if item > largest {
            largest = item;
        }
    }

    largest
}

fn main() {
    let number_list = vec![34, 50, 25, 100, 65];

    let result = largest_i32(&number_list);
    println!("The largest number is {result}");

    let char_list = vec!['y', 'm', 'a', 'q'];

    let result = largest_char(&char_list);
    println!("The largest char is {result}");
}
```

仔细分析2个函数代码几乎一样，因此可以定义一个函数，结合泛型参数来缩减代码量

理解泛型代码：函数 largest 有泛型类型 T（T是一个名称，主要通过< > 来说明这个是一个泛型。它有个参数 list，其类型是元素为 T 的 slice。largest 函数会返回一个与 T 相同类型的引用。

`fn largest<T>(list: &[T]) -> &T {`

代码如下：

```rust
fn largest<T>(list: &[T]) -> &T {
    let mut largest = &list[0];

    for item in list {
        if item > largest {
            largest = item;
        }
    }

    largest
}

fn main() {
    let number_list = vec![34, 50, 25, 100, 65];

    let result = largest(&number_list);
    println!("The largest number is {result}");

    let char_list = vec!['y', 'm', 'a', 'q'];

    let result = largest(&char_list);
    println!("The largest char is {result}");
}
```

当然这段代码是无法编译成功的：largest 的函数体不能适用于 T 的所有可能的类型。因为函数体需要比较 T 类型的值（代码中 >），但并不是所有类型都能实现该功能（即便我们只放入i32 和 char 是支持的，但系统会认为你会放入更多其他类型，存在无法进行对比的可能），所以我们需要限制 T 的类型。

### 结构体定义中的泛型

 `< >` 语法来定义结构体，它包含一个或多个泛型参数类型字段

```rust
struct Point<T> {
    x: T,
    y: T,
}

fn main() {
    let integer = Point { x: 5, y: 10 };
    let float = Point { x: 1.0, y: 4.0 };
}
```

注意： x 和 y 都是同一个类型的泛型，即具体分配值时必须相同。

如果要让x和y有不同类型，可以使用多个泛型类型参数：

```rust
struct Point<T, U> {
    x: T,
    y: U,
}

fn main() {
    let both_integer = Point { x: 5, y: 10 };
    let both_float = Point { x: 1.0, y: 4.0 };
    let integer_and_float = Point { x: 5, y: 4.0 };
}
```

当一个函数中存放太多泛型时就要考虑重构代码，分解成更小块

### 枚举定义中的泛型

```rust
enum Option<T> {
    Some(T),
    None,
}

// 多个泛型类型
enum Result<T, E> {
    Ok(T),
    Err(E),
}
```

当代码中存在多个结构体 或 枚举，如果它们之间只是值的类型不同时，可以尝试通过泛型类型来简化代码

### 方法定义中的泛型

```rust
struct Point<T> {
    x: T,
    y: T,
}

impl<T> Point<T> {
    fn x(&self) -> &T {
        &self.x
    }
}

fn main() {
    let p = Point { x: 5, y: 10 };

    println!("p.x = {}", p.x());
}
```

必须在 impl 后面声明 T，才可以在 `Point<T>`上实现的方法中使用 T 。因为 通过在 impl 之后声明泛型 T，Rust 就知道 Point 的尖括号中的类型是泛型而不是具体类型。

定义方法时可以为泛型指定限制（constraint）。例如，可以选择为 `Point<f32>` 实例实现方法，例如 没有在 impl 之后（的尖括号）声明泛型的例子，这里使用了一个具体类型 `f32`：

```rust
impl Point<f32> {
    fn distance_from_origin(&self) -> f32 {
        (self.x.powi(2) + self.y.powi(2)).sqrt()
    }
}
```

意味着 `Point<f32>` 类型会有一个方法 distance_from_origin，而其他 T 不是 f32 类型的 `Point<T>` 实例则没有定义此方法。

方法可以使用与结构体定义中不同类型的泛型：

```rust
struct Point<X1, Y1> {
    x: X1,
    y: Y1,
}

impl<X1, Y1> Point<X1, Y1> {
    fn mixup<X2, Y2>(self, other: Point<X2, Y2>) -> Point<X1, Y2> {
        Point {
            x: self.x,
            y: other.y,
        }
    }
}

fn main() {
    let p1 = Point { x: 5, y: 10.4 };
    let p2 = Point { x: "Hello", y: 'c' };

    let p3 = p1.mixup(p2);

    println!("p3.x = {}, p3.y = {}", p3.x, p3.y);
}
```

Rust通过在编译时进行泛型代码的单态化来确保效率。（就是不会慢，推荐使用泛型）

## 10.2Trait：定义共同行为

Trait特征 类似于 其他语言中 interfaces 实现的功能，但有一些差异

trait定义了 特定类型具有的功能，并可以与其他类型共享。 可以使用trait以抽象的方式 定义 共享行为。

### 定义一个trait

如果可以对不同类型 调用 相同的方法，那么这些类型就可以共享相同的行为了。trait定义了一种将方法签名组合起来的方法，目的是定义一个实现某些目的所必须的行为的集合。

例如：设计一个程序 ，多个结构体，其中一个`NewsArticle`结构体保存特定位置提交的新闻报道，另一个`SocialPost`最多包含280个字符以及提示它是新帖子、转贴还是对其他帖子的回复的元数据。 此刻创建一个名为`aggregator`的媒体聚合器库crate，用来显示可能存储在`NewArticle`或`Socialpost`实例的数据摘要，为此我们需要每个结构体能获取摘要，我们将通过在实例上调用`summarize`方法请求该摘要 ：

保存在 `src/lib.rs`

```rust
pub trait Summary {
    fn summarize(&self) -> String;
}
```

方法的具体实现代码是又后续不同类型的内部编译，看后续。

trait内可以有多个方法，一行一个方法，并以分号结尾

### 为类型实现trait

保存在 `src/lib.rs`

```rust
pub struct NewsArticle {
    pub headline: String,
    pub location: String,
    pub author: String,
    pub content: String,
}

impl Summary for NewsArticle {
    fn summarize(&self) -> String {
        format!("{}, by {} ({})", self.headline, self.author, self.location)
    }
}

pub struct SocialPost {
    pub username: String,
    pub content: String,
    pub reply: bool,
    pub repost: bool,
}

impl Summary for SocialPost {
    fn summarize(&self) -> String {
        format!("{}: {}", self.username, self.content)
    }
}
```

具体使用 ：

```rust
use aggregator::{SocialPost, Summary};

fn main() {
    let post = SocialPost {
        username: String::from("horse_ebooks"),
        content: String::from(
            "of course, as you probably already know, people",
        ),
        reply: false,
        repost: false,
    };

    println!("1 new post: {}", post.summarize());
}
```
